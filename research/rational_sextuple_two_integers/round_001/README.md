## 问题与执行范围

研究六个互异、非零有理数 a1,...,a6，至少两个为整数，且全部十五个 a_i*a_j+1 都是有理平方。正数情形和允许混合符号的情形分别保留。零可以是某条边的平方根，但不能作为集合元素。

Dujella 的 2026-08-08 版问题表将这一问题列为 Problem 3.1（PDF 第7页）。表中的 Piezas 例子含一个整数，本轮已逐项复核它的十五个平方根；它不是“两整数”问题的解。具体文献定位见完整下载包内的 sources/ledger.json；该索引的仓库写入被连接器拦截，未重试。

本轮参照只读 proofloop 仓库的角色划分和实质审查要求，记录于 workflow/roles_and_reviews.json。**实际执行是同一宿主会话中的顺序角色工作，加上四个进程的精确计算；没有启动独立 AI 智能体，也没有运行原生 ProofLoop 控制器。** GitHub Actions 重跑的是算术程序，不是 AI 角色。不能把这些记录表述成原生多智能体通过审查。

## 本轮最有用的结构性结果

设 {a,b,c} 是有理 D(1) 三元组。在椭圆曲线

    E: Y^2=(X+ab)(X+ac)(X+bc)

上，若规范点 S=(1,R)，R^2=(ab+1)(ac+1)(bc+1)，的阶恰为3，则 a,b,c 中至多一个是整数。

证明的核心是：记 z=abc，三阶条件迫使 1+z^2 为有理平方；如果 a,b 为整数，同一条件又使 z 满足首一整系数四次方程，从而 z 为非零整数。相邻整数平方之间的严格间隙给出矛盾。完整推导见 proofs/lemmas.md 的 L4，代数恒等式由 checks.py --symbolic 精确核对。

这一结论排除了把两个整数同时放进 DKMS 规范三阶种子三元组的路线，但**没有**排除两个整数出现在所添坐标中、或者种子和所添坐标各有一个整数。没有宣称该引理的优先权已经核查完毕。

另外保留了四个完整辅助论证：整数锚点的符号归约；共同邻居的全体有理参数化及 K4 等价；约分后分母的素因子约束；一整族通过初筛却只能添入两个零的退化例子。

## 精确计算结果

共同邻居写成

    x=4mn(m-n)(bn-am)/(am^2-bn^2)^2,
    gcd(m,n)=1, -H<=m<=H, 1<=n<=H.

| 实验 | 实际范围 | 结果 |
|---|---|---|
| 整数锚点图 | H=48；全部98对 1<=a<b<=50、ab+1为平方的锚点，另加4对 | 102张图，无K4 |
| 加深指定锚点 | H=96；(1,3),(1,8),(3,8),(1,120),(3,120),(8,120),(-1,1) | 7张图，无K4 |
| 已有显式构造 | DKMS 的[3]P、[5]P及DKP的F(t)；正有理参数高度<=60 | 6604次有效六元组特化，无整数元素；另有2次退化 |
| 四元组扩展 | 113045次四元组记录、339135次配对条件测试 | 4次命中均只添入两个零 |
| 五元组扩展 | 2328个不同五元组，三类显式机制 | 102917次非零新元素测试，无六元组 |

109张图一共测试了 **550135163** 对顶点。第二套程序没有导入主搜索程序，改用约分后的分数及 N/D 为平方当且仅当 ND 为整数平方的判据，重新生成所有顶点、重新测试全部550135163对顶点，并用递归算法计数三角形和K4；结果全部一致。重叠图、不同参数特化或不同输入之间可能重复，所列次数不是全局去重后的对象数。

DKP 的 F(t) 在本轮取一般有理参数，不能据论文标题声称每个被测特化都有平方分母。正负符号均由精确式子保留。五元组扩展的新元素不限高度，但扩展机制仍不是全部可能的有理扩展。

## 一个必须保留的反例测试

    [6,8,-1/8,15/8,0,0]

这个六位置列表的十五个乘积加1都是平方，却既有零又有重复，绝不是六元组。类似伪解在本轮四元组初筛中出现4次，已全部拒绝并保留记录。另一个测试 {7,329,360/12943} 说明：整数锚点不互素时，额外元素的约分后分母未必是平方。
