# Mathematical research playground

This repository stores research work explicitly requested by its owner.

## Active project

`research/rational_sextuple_two_integers/round_001/`

Question: Does there exist a set of six distinct nonzero rational numbers, at least two of them integers, such that the product of every two distinct elements plus 1 is a rational square? Both the all-positive and mixed-sign cases are tracked.

## Execution and evidence policy

ProofLoop (`Jun-feng-Li/proofloop`) is a read-only reference. Its private runtime and credentials are not copied into this public repository.

This session has no callable independent AI-agent/Jules backend. Work is explicitly labelled **single-host sequential role work**, with separately executed exact-arithmetic checkers. These checkers are not independent AI agents. Native ProofLoop controller execution and independent-agent review must not be claimed without actual receipts.

A bounded search is not a global nonexistence proof. Auxiliary lemmas, finite computations, and the unresolved main question are recorded separately. No plaintext credentials, temporary access URLs, or unrelated private material should be committed.
